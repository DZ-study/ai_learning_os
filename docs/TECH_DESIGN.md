## 2. 背景与目标
AI Learning OS 是一个基于大语言模型的个人学习管理系统。

系统通过 AI Agent 帮助用户完成：

- 学习目标规划
- 知识管理
- AI辅导
- 学习评估
- 复习强化

## 4. 详细设计（核心部分）
### 4.1 模块划分
#### 用户模块

**模块职责**

负责用户身份管理和个人学习信息管理

**核心能力**

- 用户登录（邮箱+验证码），免注册
- 用户信息管理
- 学习偏好设置

**数据**

User:
```sql
id
email
password_hash
nickname
created_at
updated_at
```
**对外提供**

获取当前用户信息
用户身份认证能力

#### 学习目标模块

**模块职责**

负责管理用户的学习目标，并作为AI规划的入口

**核心能力**

- 创建学习目标
- 查看详情
- 查看学习进度
- 放弃学习目标

**数据**

LeaningGoal:
```sql
id
user_id
title
description
current_level
target_date
status -- 未开始/进行中/已完成/已放弃/已过期
```
**依赖**
